# 03 — Transformation

Construire un modèle commun permettant de relier les observations par territoire, année scolaire et niveau d'enseignement.

## Grain cible à confirmer
Une ligne par combinaison disponible de :
- année scolaire ;
- province (et région harmonisée) ;
- niveau d'enseignement ;
- sexe, si disponible.

## Indicateurs à étudier
- taux d'abandon, à partir de la définition officielle et des données nécessaires ;
- taux de redoublement ;
- taux d'achèvement ;
- taux de transition vers le post-primaire ;
- évolution des effectifs et nouveaux inscrits ;
- indicateurs complémentaires de contexte, si leur qualité et leur disponibilité le permettent.

Ne pas recalculer un taux sans disposer de son numérateur, de son dénominateur et de sa définition officielle. Conserver les indicateurs publiés dans une colonne distincte des indicateurs recalculés.
