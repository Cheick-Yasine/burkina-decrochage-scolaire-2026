# LISEZ-MOI — dépôt de travail

- Le dépôt contient le code, les métadonnées et la documentation du projet.
- Les fichiers bruts DGESS/Data Pack restent dans l'espace de travail local et ne doivent pas être poussés sur GitHub.
- Les jeux préparés ne peuvent être partagés qu'après vérification des règles de diffusion.
- Les étapes du challenge sont : 01_collecte, 02_nettoyage, 03_transformation, 04_analyse, 05_interpretation.
- Les livrables doivent être versionnés, clairement nommés et accompagnés de leur provenance.
- Pour toute question méthodologique, distinguer abandon observé, vulnérabilité et risque prédit.
