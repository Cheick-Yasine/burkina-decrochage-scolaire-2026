# Documentation du projet

La documentation finale est limitée à 15 pages maximum selon le document du challenge.

Plan conseillé :
1. Le défi et la question retenue.
2. Les données, sources et limites.
3. La préparation et les transformations.
4. La méthode statistique ou le modèle.
5. Les résultats et visualisations.
6. La réponse au défi, l'utilité pour le décideur, les limites et les suites possibles.

Conserver ici le dictionnaire des variables, le schéma de données, la méthodologie et le rapport final.
