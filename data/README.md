# Données

Les données du challenge sont organisées en trois niveaux :

- `raw/` : copies sources non modifiées, conservées localement ;
- `processed/` : données nettoyées et harmonisées ;
- `final/` : tables d'analyse agrégées et autorisées à la diffusion.

Ne pas pousser de données brutes ou de fichiers dont les conditions de diffusion ne sont pas confirmées. Le classeur DGESS transmis pour le challenge reste local. Documenter pour chaque source le producteur, le titre, l'année, le chemin d'origine, la date de récupération et les limites connues.
