# Tests et contrôles qualité

Prévoir des contrôles automatisés sur :
- unicité des clés attendues ;
- domaines de valeurs et unités ;
- cohérence des années scolaires ;
- absence de lignes de total dans les tables d'analyse ;
- cohérence des agrégats avec les publications sources ;
- valeurs manquantes et ruptures de séries ;
- cohérence des jointures géographiques.
