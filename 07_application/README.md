# Application web

Plateforme cible de vigilance scolaire couvrant trois cycles : primaire, post-primaire et secondaire.

Fonctions envisagées :
- carte par région/province selon la géographie réellement disponible ;
- filtre par cycle, année scolaire, sexe et indicateur ;
- couches contextuelles sourcées ;
- fiches territoires avec valeurs observées, signaux indirects et estimations séparés ;
- alertes explicables et recommandations.

L'interface ne doit afficher une prédiction que si le modèle a été évalué et ses limites exposées.
