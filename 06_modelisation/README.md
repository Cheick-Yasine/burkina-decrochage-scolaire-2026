# Modélisation — Score de Risque de Décrochage

Ordre de travail :
1. définir les indicateurs observés ;
2. construire un indice SRD transparent ;
3. tester la robustesse et la sensibilité ;
4. entraîner un modèle prédictif seulement si une cible d'abandon fiable et un historique suffisant sont disponibles ;
5. évaluer temporellement et documenter les limites.

Un indice composite n'est pas une probabilité. Une baisse des effectifs n'est pas un abandon observé.
